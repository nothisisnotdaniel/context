# 062 Links to headings

As a Context user, I want to link to a heading inside a note and jump between headings, so that long notes are easy to navigate.

## What

`[[Note#Heading]]` links to a heading inside a note (matched ignoring case; a missing heading opens the note at the top), and the desktop app shows an outline panel of a long note's headings to jump between them. Stored in the index with the link (a parser version bump).

## Why

Links to a whole long note make me scroll for the relevant part. Heading links and an outline panel fix that.
