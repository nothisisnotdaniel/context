# 010 Editor dirty marker

As a Context user, I want to see when a note has unsaved changes, so that I don't close it thinking it's saved.

## What

The desktop editor shows when a note has unsaved changes (for example a dot next to the note name) and clears it after a save.

## Why

Without a marker there's no way to tell whether the last edit was saved. A small dot that clears on save is the usual signal.
