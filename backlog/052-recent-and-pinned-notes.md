# 052 Recent and pinned notes

As a Context user, I want my recently opened and pinned notes in the desktop sidebar, so that the notes I use most are one click away.

## What

A sidebar section in the desktop app with the last opened notes and notes the user pins, kept in a small settings file next to the notes.

In the sidebar note list, every pinned note shows a small pin icon next to its name (inline SVG shipped with the app, with an accessible name such as "Pinned" and readable in light and dark mode), so you can see at a glance which notes are pinned.

## Why

Most work touches the same few notes, and finding them again each time is slow.
