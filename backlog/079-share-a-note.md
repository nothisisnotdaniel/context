# 079 Share a note

As a Context user, I want to export a note as a clean HTML or PDF file, so that I can send it to colleagues who don't use Context.

## What

Export one note from the desktop app as a clean HTML file or PDF (Markdown rendered, tags and links shown as plain text, images from attachments embedded) to send to colleagues. An option leaves out lines tagged `#private`. For a sensitive note, the export warns that the copy is not encrypted, like `/export`.

## Why

Colleagues can't read raw Markdown with tags and links. An option to leave out `#private` lines, and a warning for sensitive notes, keeps sharing safe.
