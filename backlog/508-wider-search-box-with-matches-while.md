# 508 Wider search box with matches while typing

As a user, I want a longer search box that shows matches as I type, so that I find a note without pressing Return.

Category: ux

## What

Make the search input in the top bar's search popover wider, and show matching notes while typing (debounced), using the existing full-text search.

## Why

The box is short for longer queries, and results only appear after submitting.

## Notes

From GitHub issue #3 (Feature Requests). Keep the search fast on large note sets; the spec sets the debounce and result limit.
