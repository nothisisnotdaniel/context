# 008 Desktop import and export

As a Context user, I want to import and export notes through file pickers in the desktop app, so that I can move notes in and out without the console.

## What

Import Markdown files through a file picker and export a note to a chosen path, with the same checks as `/import` and `/export`. Builds on desktop writes.

## Why

Import and export already exist as console commands with careful checks. The desktop app needs the same, with the same checks, before the console can go.
