# 509 Paste pictures into notes

As a user, I want to paste a picture from the clipboard into a note, so that I can add screenshots quickly.

Category: feature

## What

When the clipboard holds an image, pasting into a note saves it as an attachment the same way attached files are stored, and inserts an image link at the cursor so it shows inline. Apply the existing attachment size limits.

## Why

Adding a screenshot now means saving a file first and attaching it.
