# 082 Review dates

As a Context user, I want to mark when a note should be checked again, so that important knowledge stays up to date instead of going stale.

## What

A `review:yyyy-MM-dd` line in a note marks when it should be checked again. On that day the note shows in a "To review" sidebar group (and in the morning briefing) with buttons to set a new date or remove the line, so knowledge gets confirmed or updated instead of going stale.

## Why

Reference notes slowly become wrong without anyone noticing. A review date brings the note back on that day with quick buttons to confirm or reschedule.
