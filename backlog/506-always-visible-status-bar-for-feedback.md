# 506 Always-visible status bar for feedback messages

As a user, I want every feedback message in one status bar at the bottom of the window, so that I always know where to look.

Category: ux

## What

Add a status bar along the bottom of the desktop window that is always visible, and show every feedback text there (results of saves, shares, updates, errors) instead of the status lines spread over the panels. Keep the accent and red colours and announce messages to screen readers.

## Why

Feedback now appears in different places and can scroll out of view.

## Notes

From GitHub issue #3 (Feature Requests). The spec lists each current status line it moves.
