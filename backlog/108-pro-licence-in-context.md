# 108 Pro licence in Context

As a Suite Pro buyer, I want Context to use the licence I activated in Times, so that I activate once for the whole suite.

## What

Context reads the shared activation file and keychain item from Times#39 with the same rules (build date before expiry, monthly re-check, 30-day grace). The desktop app's settings show the Pro state and can activate a key the same way when Times isn't installed. Pro features show a short, friendly locked hint instead of failing. Full path, high risk: secrets and a shared data format.

## Why

Dossier, meeting flow, handover pack and the MCP server are Pro. One shared format keeps the apps in step and the buyer's experience simple.
