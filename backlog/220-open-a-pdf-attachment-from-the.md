# 220 Open a PDF attachment from the keyboard

As a Context user who works with the keyboard, I want to open a PDF attached to a note without the mouse, so that attachments are as reachable as the rest of the app.

## What

Give PDF attachment links in the note view a keyboard route (focusable and opened with Enter, with a visible focus ring), using the same checked launcher path as a click. Add tests.

## Why

Today a PDF attachment can only be opened with a click, so keyboard users can't reach it.
