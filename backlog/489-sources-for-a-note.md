# 489 Sources for a note

As someone who writes notes from tickets, mails and web pages, I want to attach the source to the note and open it from there, so that I can always get back to where something came from.

Category: feature

## What

A note can list sources as `source::` lines: a work item (`#<n>`/`AB#<n>`), an email (sender and date, from the mail digest), a web link (https only) or free text. The note page shows them in a Sources box with an Open button per source (a link opens in the browser, a work item its page, an email in Outlook where possible) and a shortcut to open the first one.

## Why

assistant keeps sources per thought. Context has work item references and plans an email-to-note item, but no general sources.
