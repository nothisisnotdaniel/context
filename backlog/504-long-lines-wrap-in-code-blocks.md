# 504 Long lines wrap in code blocks

As a user, I want long lines in code blocks to wrap, so that I can read them without scrolling sideways.

Category: ui

## What

Wrap long lines in fenced code blocks in the note editor and view, keeping indentation, instead of a horizontal scroll bar. Copying a block still copies the original lines.

## Why

Long commands and log lines are cut off and need sideways scrolling.

## Notes

From GitHub issue #3 (Feature Requests): "Code blocks should have line break".
