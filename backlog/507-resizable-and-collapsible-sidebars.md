# 507 Resizable and collapsible sidebars

As a user, I want to resize both sidebars and collapse them with an icon, so that I can give the note more room.

Category: feature

## What

Let the user drag the inner edge of the left and the right sidebar to resize it, and collapse or expand each one with an icon button. Remember the widths and collapsed states between sessions. Keyboard users can do both too.

## Why

The sidebars have a fixed width, so the note can't use the space when they aren't needed.
