# 522 Visible hint after Esc in a code block

As a user, I want a small hint after I press Esc in a code block, so that I know the next Tab will leave the block.

Category: ui

## What

Show a subtle hint (e.g. status text or caret style) while the Esc-then-Tab exit is armed, cleared on the next key or caret move.

## Why

The Esc exit is silent today, so users may not find it.
