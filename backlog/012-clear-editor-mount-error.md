# 012 Clear editor mount error

As a Context user, I want a clear message when the editor fails to start, so that I don't think my note file is broken.

## What

When the editor fails to load, say so (for example "The editor couldn't start") instead of "Can't read <name>.", which reads as a file problem.

## Why

Today an editor failure says "Can't read <name>.", which reads as a file problem and might make me go looking for a damaged note.
