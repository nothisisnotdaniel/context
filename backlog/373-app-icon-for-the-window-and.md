# 373 App icon for the window and the taskbar

As the user, I want Context to show its own icon in the window, the Dock and the taskbar, so that I can find it at a glance among my open apps.

## What

Context.Desktop shows the default icon. Add a Context app icon (.icns for macOS, .ico for Windows, a PNG for Linux), set it on the Photino window and in the app bundle and publish settings, so the window title bar, the Dock/taskbar and the app switcher all show it. Include the source artwork in the repo.

## Why

The user asked for an icon for the window and the task bar: with the default icon Context is hard to pick out.
