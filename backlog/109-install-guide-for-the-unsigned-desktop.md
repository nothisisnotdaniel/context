# 109 Install guide for the unsigned desktop app

As a new user, I want clear steps to open the unsigned desktop app on macOS and Windows, so that a security warning doesn't stop me.

## What

A README section (reused by the landing page) with the one-time steps: macOS right-click → Open, or System Settings → Privacy & Security → Open Anyway; Windows SmartScreen → More info → Run anyway. Also how to check the download's SHA-256 against the release page, and why the build isn't signed.

## Why

Suite Pro ships unsigned to stay at zero cost. Without plain steps, macOS and Windows warnings look like malware and lose buyers.
