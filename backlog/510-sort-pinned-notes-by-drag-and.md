# 510 Sort pinned notes by drag and drop

As a user, I want to drag pinned notes into the order I like, so that the ones I need most are at the top.

Category: feature

## What

Let the user reorder the pinned notes list by drag and drop, with a keyboard alternative (for example move up and down). Save the order in the pinned list file.

## Why

Pinned notes keep their pin order, which may not be the order the user wants.

## Notes

From GitHub issue #3 (Feature Requests). Related: #366 (roll back the in-memory change when the pinned file write fails).
