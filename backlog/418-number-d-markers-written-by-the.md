# 418 Number #!d markers written by the CLI and by merges

As a Context user, I want new #!d markers written by the CLI or a merge to get a number right away, so that every decision in the log has a number without opening the note in the app.

Category: feature

## What

Number bare #!d markers on the CLI write paths and on note merges, the same way SaveNote does, or document clearly why a path cannot.

## Why

Job 343 left the CLI and merges unnumbered on purpose; those decisions show as unnumbered until the next desktop save, which is easy to miss.
