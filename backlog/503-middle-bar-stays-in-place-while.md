# 503 Middle bar stays in place while the note scrolls

As a user, I want the bar above the note to stay visible, so that its buttons are in reach however far I scroll.

Category: ui

## What

Keep the bar at the top of the middle (note) column fixed while the note content scrolls beneath it, in the desktop app. Only the content area scrolls.

## Why

Today the middle bar scrolls away with the note, so reaching its controls in a long note means scrolling back up.

## Notes

From GitHub issue #3 (Feature Requests). The spec should name which bar this is (the note's header bar under the top bar) and check the outline sidebar still scrolls on its own.
