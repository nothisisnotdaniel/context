# 096 Excalidraw drawings

As a Context user, I want Excalidraw drawings shown inline in notes, so that sketches live with the notes they explain.

## What

`.excalidraw` files in the notes folder (or attachments) show inline in a note as a read-only drawing, with a button to open them in Excalidraw for editing. No scripts from the file run. Builds on attachments.

## Why

Drawings kept elsewhere lose their context. Showing them read-only with no scripts from the file, and opening Excalidraw to edit, keeps it safe.
