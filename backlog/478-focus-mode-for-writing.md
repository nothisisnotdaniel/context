# 478 Focus mode for writing

As someone writing a long note, I want a focus mode that hides everything but the editor, so that I can write without the sidebar and panels pulling my attention.

Category: ux

## What

A toggle (palette `/focus`, a shortcut and a button in the editor's menu) that hides the sidebar, the panels under the editor and the status line and centres the editor at a readable width. Esc or the same toggle leaves it. Saving, the format bar and the editor's shortcuts keep working. The state is not kept across restarts.

## Why

assistant has a focus mode for writing. Context always shows the sidebar and panels, which is busy for long notes.
