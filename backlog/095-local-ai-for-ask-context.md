# 095 Local AI for Ask Context

As a Context user, I want Ask Context to be able to use a model running on my own machine, so that questions and note passages never leave the computer.

## What

Run the model on this machine through Ollama or LM Studio (their local HTTP API on localhost), so questions and note passages never leave the computer. A provider choice in the settings next to the Claude API. Builds on Ask Context.

## Why

Some notes are too private for any cloud model. Ollama and LM Studio offer local HTTP APIs, so this can be a provider choice in the settings.
