# 445 Say when the date range doesn't apply to a tag filter

As a Context user, I want to be told when the date boxes don't affect what I'm searching, so that I don't think a tag filter was narrowed when it wasn't.

Category: ux

## What

When the search text is a tag filter (#name), the from and to boxes have no effect and nothing says so. Disable them with a short hint, or apply the range to tag filters too.

## Why

The UX review of job 379 flagged it in both rounds. Without a hint the range looks like it works.
