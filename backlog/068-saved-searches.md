# 068 Saved searches

As a Context user, I want to save a search or tag filter as a sidebar entry, so that views I use often are one click away.

## What

Save a search or a tag filter (for example `#1234 and not #done`) under a name as a sidebar entry in the desktop app that shows its current results; stored in the small settings file. Builds on full-text search.

## Why

Typing the same filter (for example `#1234 and not #done`) again and again is tedious.
