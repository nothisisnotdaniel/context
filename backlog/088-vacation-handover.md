# 088 Vacation handover

As a Context and Times user, I want a handover note drafted before my absence, so that my colleagues get what they need without me compiling it by hand.

## What

Before absence days booked in Times (read-only from Times' files), Context offers to create a handover note listing open todos, waiting-for items, meetings during the absence and the project pages of work items booked in the last two weeks, for the user to edit and share. Also a button and a CLI command for any date range. Builds on Times' absence days, the waiting-for list and project pages.

## Why

Before a vacation, collecting open todos, waiting-for items, meetings and active projects takes time when it's scarcest. A draft I edit and share saves most of it.
