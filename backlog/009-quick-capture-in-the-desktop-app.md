# 009 Quick capture in the desktop app

As a Context user, I want a capture box in the desktop app that adds a time-stamped line to my inbox, so that I can jot something down in seconds.

## What

A capture box that appends a time-stamped line to `inbox.md` through the existing `Inbox.Capture` (the CLI's `context capture` already does this); tags in the text work as usual. Groundwork for voice notes.

## Why

Capturing a thought quickly is the main way things get into Context, and the CLI already does it. It's also the groundwork voice notes build on.
