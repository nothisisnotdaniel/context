# 011 Keyboard focus for chips

As a Context user, I want to reach tag and link chips with Tab and open them with Enter, so that I can navigate notes without the mouse.

## What

Tag and link chips in the desktop editor can be reached with Tab and opened with Enter, with a visible focus ring.

## Why

Chips that only work with the mouse leave keyboard users out and slow everyone down. A visible focus ring shows where you are.
