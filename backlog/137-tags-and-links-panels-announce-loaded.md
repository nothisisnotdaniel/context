# 137 Tags and links panels: announce loaded rows

As a screen reader user, I want the tags and links panels to announce when their rows change, so that I know new results arrived.

## What

Add a live announcement (e.g. a polite status line with the row count) when TagsPanel or LinksPanel finishes loading.

## Why

Review-ux (job 137): the status lines are role=status, but row changes have no live announcement.
