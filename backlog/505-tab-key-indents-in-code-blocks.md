# 505 Tab key indents in code blocks

As a user, I want the Tab key to insert indentation inside a code block, so that I can write code in a note.

Category: feature

## What

Inside a fenced code block, Tab inserts indentation (and Shift+Tab removes it) instead of moving focus. Outside code blocks Tab behaves as today. Give a keyboard way out of the block (for example Esc then Tab) so keyboard users aren't trapped.

## Why

Tab currently doesn't work in code blocks, so indenting code is awkward.
