# 073 Mail digest

As a Context user, I want follow-ups, todos and meeting notes suggested from my mail, so that I don't miss what mail asks of me.

## What

From the mail Context reads (Outlook as a source), suggest follow-ups, todos and meeting notes in a review list in the desktop app; nothing is added to notes or todos until the user accepts each one. Runs on the machine; an AI model is only used if Ask Context's model setting allows it, with the same ask-each-time rule. Builds on Outlook as a source and inbox triage.

## Why

Mail holds many small commitments that never make it into todos. Suggestions that I accept one by one keep me in control, and the model rule from Ask Context keeps it private.
