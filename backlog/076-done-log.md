# 076 Done log

As a Context user, I want finished todos kept in a done log, so that I can see what I got done each week.

## What

A finished todo is appended to `done.md` (date done, its text, due date and tags) instead of disappearing, and the desktop app has a Done view by week. The weekly review shows the week's part of it. Recurring todos log each time they are done.

## Why

Finished todos currently just disappear, which makes weekly reviews and standups harder than they need to be.
