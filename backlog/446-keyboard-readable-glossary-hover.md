# 446 Keyboard-readable glossary hover

As a keyboard user, I want to read a glossary term's meaning without a mouse, so that the editor's hover works for me too.

Category: ux

## What

The editor shows glossary meanings only through the native title hover on span.glossary-term, which can't be reached from the keyboard. Show the meaning in an accessible way (for example on focus or a key).

## Why

Job 380's ux review: the native title hover can't be read from the keyboard.
