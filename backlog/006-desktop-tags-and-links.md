# 006 Desktop tags and links

As a Context user, I want a tags view and a links panel in the desktop app, so that I can find related notes there as I can in the console.

## What

A tags view in the desktop app (all tags with counts; click one to open the existing `TagPanel` list of its notes) and a links panel for the open note (links in and out, shared tags), using the existing `TagIndex` queries.

## Why

Tags and links are how notes connect, and the queries already exist in `TagIndex`. Without them the desktop app can't replace the console.
