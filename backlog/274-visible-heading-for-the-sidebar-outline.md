# 274 Visible heading for the sidebar outline

As a Context user, I want the outline in the right sidebar to have a small visible heading, so that I can tell at a glance what the list of links is.

## What

Add a small visible label (for example "Outline") above the outline in the right sidebar, styled like the other sidebar section headings, keeping aria-label or replacing it with aria-labelledby. Light and dark mode.

## Why

Job 210 put the outline in the right sidebar with only aria-label="Outline"; the ux review noted that sighted users see an unlabelled list of links next to other sidebar content.
