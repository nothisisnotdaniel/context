# 004 Desktop notes

As a Context user, I want to create, rename and delete notes in the desktop app, so that I don't need the console for basic note management.

## What

Create, rename and delete notes in the desktop app (names checked like `/new`, delete asks first), and open a note in the default editor as a fallback until desktop editing exists. Builds on desktop writes.

## Why

The desktop app is becoming the main way to use Context, and managing notes is the most basic thing it needs. Opening a note in the default editor bridges the gap until desktop editing exists.
