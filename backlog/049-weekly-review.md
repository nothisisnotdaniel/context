# 049 Weekly review

As a Context user, I want one screen showing my last week and the next one, so that a weekly review takes minutes instead of digging through notes.

## What

Desktop app, plus a CLI command where it fits. A `/review` command shows on one screen the notes changed in the last 7 days, the todos done and the todos overdue, and next week's appointments.

## Why

Changed notes, done and overdue todos, and next week's appointments are spread across views today.
